# Neptun — статический сайт (HTML / CSS / JS)

Сайт разобран из одного SPA-файла `neptun.html` (1,4 МБ, все картинки в base64,
страницы переключались через JS) в обычный многостраничный проект.
Внешний вид не изменён: вёрстка поэлементно сверена с оригиналом на ширинах 390 / 800 / 1280 / 1440 px.

## Структура

```
neptun/
├── index.html                 главная
├── blog.html                  список статей + фильтр по категориям
├── blog/                      7 статей (отдельный HTML на каждую)
│   ├── virtualna-ats.html
│   ├── propushcheni-dzvinky.html
│   ├── avtodailer.html
│   ├── hlr-perevirka.html
│   ├── ai-dzvinky.html
│   ├── analityka-dzvinkiv.html
│   └── mizhnarodna-telefonia.html
├── docs/                      14 внутренних страниц разделов
│   ├── ats.html  ats-connect.html  ats-features.html  ats-numbers.html
│   ├── ats-crm.html  ats-pricing.html
│   ├── biz.html  biz-trust.html  biz-intl.html  biz-sales.html
│   └── biz-sms-api.html  biz-callcenter.html  biz-fast.html  biz-ecom.html
└── assets/
    ├── css/
    │   ├── base.css           переменные, ресет, типографика, кнопки
    │   ├── layout.css         шапка, мега-меню, моб. меню, футер, sticky-CTA
    │   ├── components.css     секции, заголовки, слайдеры, точки, поля форм, пузырьки
    │   ├── home.css           секции главной
    │   ├── blog.css           блог (тёмная тема), карточки статей
    │   ├── article.css        страница статьи
    │   └── docs.css           внутренние страницы разделов
    ├── js/
    │   ├── main.js            общее: меню, мега-меню, слайдеры, точки, sticky, пузырьки
    │   ├── home.js            табы бизнеса, аккордеоны, live-дашборд, иконки отзывов
    │   └── blog.js            фильтр статей
    └── img/                   63 изображения .webp (имена = ключи из исходника)
```

Подключение CSS по страницам (порядок важен, он сохраняет каскад):

| Страница   | CSS                                                    | JS                 |
|------------|--------------------------------------------------------|--------------------|
| index      | base, layout, components, home                         | main, home         |
| blog       | base, layout, components, blog                         | main, blog         |
| blog/*     | base, layout, components, blog, article                | main               |
| docs/*     | base, layout, components, docs                         | main               |

Сборщики и зависимости не нужны: открывается двойным кликом по `index.html`
или через любой локальный сервер (`npx serve .`, `python3 -m http.server`).

## Что изменилось по сравнению с исходником

- SPA-роутер (`#blog`, `#post/…`, `#doc/…`) удалён, теперь это реальные страницы и ссылки,
  поэтому каждая статья и раздел индексируются отдельно.
- Статьи и разделы больше не рендерятся из JSON в JS, контент лежит прямо в HTML.
- У каждой страницы свой `<title>` и `<meta name="description">` (для статей взяты SEO-описания из исходника).
- Картинки вынесены в файлы `assets/img/*.webp` вместо base64.
- CSS разбит на модули, дубли объединены, «мёртвые» правила, которые перебивались
  каскадом и ни на что не влияли, удалены (см. ниже).
- Кнопки «Отримати консультацію» на страницах статей и разделов ведут к форме (`index.html#form`),
  а не просто наверх главной.
- Исправлено: на планшете при `prefers-reduced-motion` ракушка в hero продолжала анимироваться.

## Этап 2 — исправленные косяки вёрстки

**Десктоп / каскад**
- Вернул десктопные стили, которые перебивались мобильными: крупный заголовок футер-CTA (38/44px),
  отступы футер-CTA, формы консультации и ряда табов, ширина описания в футере.
- Шапка: на 1000–1099px пункты меню обрезались, теперь полная навигация показывается с 1100px, а до этого работает бургер.
- Hero: подпись «Підключайтеся і вже через 15 хвилин…» на десктопе лежала на морском дне. Нижний отступ теперь растёт вместе с картинкой дна.
- «Переваги»: заголовки карточек стоят на одной линии, иллюстрации прижаты книзу.
- «Шлях клієнта»: кнопки в блоке «Потрібні дзвінки вже зараз?» выровнены по левому краю, как текст.
- Слайдеры (проблемы, экосистема, отзывы): затемнение по краям съедало первую и последнюю карточку.
  Теперь маска стоит только с той стороны, где есть ещё карточки, а неактивная стрелка скрывается.
- Отзывы: иконка прилипала к нижнему краю карточки, добавлен отступ.
- «Нам довіряють» и фильтры блога центрируются, когда помещаются (и скроллятся, когда нет).
- Футер-CTA: у русалки была видна прямоугольная акварельная подложка, края растворены маской. Картинка не растягивается больше своих 360px.
- Live-дашборд: убран неподключённый шрифт `Unbounded`.

**Мобильная версия**
- Мобильное меню с раскрытым разделом было выше экрана, нижние пункты были недосягаемы. Теперь меню скроллится.
- В мобильном меню добавлен пропущенный пункт «Номери з SMS, API та автоматизацією».
- Липкая кнопка «Підключити за 15 хвилин» больше не перекрывает низ футера.

**Блог, статьи, разделы**
- Кнопка «Отримати консультацію» в форме блога снова на всю ширину (на планшете и десктопе была узкой).
- «Показати більше» работает: сначала 6 статей, остальные по кнопке. Учитывает фильтр.
- Статья: обложка не растягивается на весь экран, а стоит в контейнере. Добавлены форма консультации и футер (раньше страница обрывалась).
- Разделы: боковое меню растягивалось на всю высоту колонки и не «прилипало» при скролле. Добавлен футер.
- © 2024 → © 2026 везде.

**Разметка, доступность, производительность**
- Формы стали настоящими `<form>`: поля с `name`, `required`, проверка телефона, кнопка `type="submit"`.
  Отправка пока не подключена: валидная форма генерирует событие `neptun:lead` с данными, на этапе WordPress сюда подключится обработчик.
- У всех картинок есть `width/height` (нет скачков вёрстки при загрузке), всё ниже первого экрана грузится лениво (`loading="lazy"`).
  Осмысленные `alt` у логотипов, обложек статей и инфографики.
- Удалены 6 скрытых картинок в отзывах (грузились, но не показывались).
- `aria-expanded` у бургера, мега-меню и аккордеонов; `role="tab"`/`aria-selected` у табов; подписи у иконок-ссылок; видимый фокус для клавиатуры; мега-меню закрывается по Esc.
- Телефон и e-mail в футере блога стали кликабельными (`tel:` / `mailto:`).

## Осталось на следующие этапы

- Иконки сделаны эмодзи (✈️ 💬 📞 📷), на разных ОС выглядят по-разному. Заменю на SVG на этапе улучшений.
- «Екосистема» на мобильном: 8 карточек подряд, очень длинный блок. Стоит сделать слайдер (этап 3).
- Переключатель языка — заглушка (на WordPress — Polylang/WPML).
- Ссылки на соцсети и мессенджеры, «Політика конфіденційності», «Увійти»/«Зареєструватися» ведут в никуда: нужны реальные адреса.
- Пункт «Ціни» ведёт на FAQ: отдельного блока с ценами нет.
