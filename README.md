# Neptun — статический сайт (HTML / CSS / JS)

Сайт разобран из одного SPA-файла `neptun.html` (1,4 МБ, все картинки в base64,
страницы переключались через JS) в обычный многостраничный проект.
Внешний вид не изменён: вёрстка поэлементно сверена с оригиналом на ширинах 390 / 800 / 1280 / 1440 px.

## Структура

```
neptun/
├── index.html                 главная
├── blog.html                  список статей + фильтр по категориям
├── blog/                      7 статей (отдельный HTML на каждую)
│   ├── virtualna-ats.html
│   ├── propushcheni-dzvinky.html
│   ├── avtodailer.html
│   ├── hlr-perevirka.html
│   ├── ai-dzvinky.html
│   ├── analityka-dzvinkiv.html
│   └── mizhnarodna-telefonia.html
├── docs/                      14 внутренних страниц разделов
│   ├── ats.html  ats-connect.html  ats-features.html  ats-numbers.html
│   ├── ats-crm.html  ats-pricing.html
│   ├── biz.html  biz-trust.html  biz-intl.html  biz-sales.html
│   └── biz-sms-api.html  biz-callcenter.html  biz-fast.html  biz-ecom.html
└── assets/
    ├── css/
    │   ├── base.css           переменные, ресет, типографика, кнопки
    │   ├── layout.css         шапка, мега-меню, моб. меню, футер, sticky-CTA
    │   ├── components.css     секции, заголовки, слайдеры, точки, поля форм, пузырьки
    │   ├── home.css           секции главной
    │   ├── blog.css           блог (тёмная тема), карточки статей
    │   ├── article.css        страница статьи
    │   └── docs.css           внутренние страницы разделов
    ├── js/
    │   ├── main.js            общее: меню, мега-меню, слайдеры, точки, sticky, пузырьки
    │   ├── home.js            табы бизнеса, аккордеоны, live-дашборд, иконки отзывов
    │   └── blog.js            фильтр статей
    └── img/                   63 изображения .webp (имена = ключи из исходника)
```

Подключение CSS по страницам (порядок важен, он сохраняет каскад):

| Страница   | CSS                                                    | JS                 |
|------------|--------------------------------------------------------|--------------------|
| index      | base, layout, components, home                         | main, home         |
| blog       | base, layout, components, blog                         | main, blog         |
| blog/*     | base, layout, components, blog, article                | main               |
| docs/*     | base, layout, components, docs                         | main               |

Сборщики и зависимости не нужны: открывается двойным кликом по `index.html`
или через любой локальный сервер (`npx serve .`, `python3 -m http.server`).

## Что изменилось по сравнению с исходником

- SPA-роутер (`#blog`, `#post/…`, `#doc/…`) удалён, теперь это реальные страницы и ссылки,
  поэтому каждая статья и раздел индексируются отдельно.
- Статьи и разделы больше не рендерятся из JSON в JS, контент лежит прямо в HTML.
- У каждой страницы свой `<title>` и `<meta name="description">` (для статей взяты SEO-описания из исходника).
- Картинки вынесены в файлы `assets/img/*.webp` вместо base64.
- CSS разбит на модули, дубли объединены, «мёртвые» правила, которые перебивались
  каскадом и ни на что не влияли, удалены (см. ниже).
- Кнопки «Отримати консультацію» на страницах статей и разделов ведут к форме (`index.html#form`),
  а не просто наверх главной.
- Исправлено: на планшете при `prefers-reduced-motion` ракушка в hero продолжала анимироваться.

## Найденные проблемы (на этап 2, «косяки вёрстки»)

1. **Десктопные стили не применялись.** В исходнике часть desktop-правил стояла в CSS
   *раньше* мобильных и перебивалась ими. В итоге на десктопе не работали:
   размер заголовка футер-CTA (задумано 38/44px, по факту 28px), отступы `.fcta`,
   ширина/отступы русалки `.fmer` и волны `.fwave`, padding и margin-top формы,
   max-width описания в футере, отступы ряда табов `.tabs`. Сейчас сохранено
   *фактическое* поведение, задуманное нужно вернуть осознанно.
2. В live-дашборде цифры KPI заданы шрифтом `Unbounded`, который не подключён (рисуется fallback).
3. В карточках отзывов грузятся 6 растровых картинок, которые скрыты (`display:none`) и заменены SVG-иконками. Лишний трафик.
4. В мобильном меню «Для бізнесу» нет пункта «Номери з SMS, API та автоматизацією» (в мега-меню он есть).
5. Формы не работают: нет `<form>`, `name`, валидации; кнопка «Отримати консультацію» — это `href="#"`.
6. «Показати більше» в блоге ничего не делает; соцсети и мессенджеры ведут на `#`.
7. У картинок нет `alt`, `width/height` (сдвиг вёрстки при загрузке) и `loading="lazy"`.
8. У страниц статей и разделов нет футера.
9. В футере главной стоит © 2024, в футере блога © 2026.
10. Переключатель языка — нерабочий `<span>`; у кнопок мега-меню и аккордеонов нет `aria-expanded`.
11. Иконки сделаны эмодзи (✈️ 💬 📞 📷), поэтому на разных ОС выглядят по-разному.
12. В пункте меню «Ціни» ссылка ведёт на FAQ, отдельного блока с ценами нет.
